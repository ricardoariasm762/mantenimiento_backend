# Mantenimiento Predictivo Backend - Diagnóstico Inteligente de Fallas Vehiculares

Backend desarrollado con **Spring Boot 3** y modelos de Machine Learning (ONNX Runtime) para el diagnóstico predictivo y prescriptivo de fallas automotrices a partir de telemetría y descripciones en lenguaje natural.

## 🛠️ Tecnologías Principales
- **Java 21** & **Spring Boot 3.4.2**
- **Spring Data JPA** & **PostgreSQL**
- **ONNX Runtime (Java)**
- **Spring AI** (OpenAI / Gemini integration) & clasificador heurístico NLP
- **Python / Scikit-Learn** (Entrenamiento del modelo Random Forest)
- **Maven**
